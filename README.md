# BN Electricals Hub

Sure. Create a modern, premium, fully responsive e-commerce website for BN Electricals and Home Appliances, a trusted Nigerian supplier of home appliances, electrical materials, and building materials. The site should feature a clean, premium design with blue, white, and gold as the main colors. You’ll have a product catalog with clear categories for home appliances, electrical materials, building supplies, and a dedicated section for professional installation services. Those services include air conditioner setup, TV wall mounting, ceiling fan installation, electrical wiring, lighting installation, inverter systems, and generator setup. Each product page will display the product price, an optional professional installation fee, estimated installation time, and warranty information. Customers can buy products only or add installation during checkout. And then, you know, you can have a booking system for installation dates and times. The site should also include online payments, nationwide delivery, WhatsApp support, a customer login area, and an admin dashboard for managing products, installation requests, and customer records. Basically, you wanna project BN Electricals as reliable, modern, and customer focused.
